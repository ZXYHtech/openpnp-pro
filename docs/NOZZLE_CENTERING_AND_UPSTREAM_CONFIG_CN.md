# 吸嘴成像中心自动调优与原版配置兼容

机器菜单新增“N1 / N2 底部视觉中心自动调优”。清空所有吸嘴并复位后，可一次依次处理全部吸嘴，也可只处理选中的吸嘴。画面显示当前角度、识别圆及测量进度。启用、停用和撤销不要求机器已复位，吸嘴载料或机器忙时禁止改变状态。

每个旋转角度采两张图，四个等间隔角度估计固定中心偏差，再换四个角度独立复核。临时修正只有在平均中心偏差改善、复测差不超过 0.03 mm 且配置未改变时才保存；失败或取消恢复该吸嘴原值。识别在原吸嘴流水线的克隆中进行，圆检测使用至少 4 倍超采样和 0.5 mm 精调搜索范围，原流水线参数保持不变。

结果保存在配置目录的 `pro-nozzle-vision-centering.json`，按底部相机、头、吸嘴及已装吸嘴尖身份隔离，并核对原校准和安装偏移。此工具调整底部相机的成像到达位置，不替换吸嘴偏心模型或修改头偏移。静拍、预旋转静拍、异步识别及实验飞拍都将新增成像平移还原到原贴装参考坐标，再作原有旋转与容差处理。平均居中结果不能等同于每个角度的残余误差，更不能当作整机贴装精度。

## 原版启动失败与兼容存储

本机原版严格读取 `packages.xml` 时首先在 Pro 的 `geometry-fingerprint` 属性报错。比对已安装原版与 Pro 的序列化定义，差异集中在封装元数据、器件别名/显示名、贴装点显示名和飞达识别置信度扩展。

公共 XML 现在保持原版可识别的字段，Pro 扩展另存到同目录的 `<原文件名>.pro.xml`。Pro 载入时按对象身份合并，原版修改的公共参数不被旧扩展覆盖；对象重排、删除和替换不会按列表位置错配。旧文件迁移先保留 `.pre-pro-compat.bak`；常规保存保留原配置备份，扩展文件也保留 `.bak`。新自动居中数据独立保存，不进入公共 XML。

已用本机两套实际安装的原版 OpenPnP 2.5（二者安装目录分别为 `openpnp`、`openpnp-20260124`）读取修复后的实际封装、器件、视觉及机器配置，均通过。该结果覆盖这两套安装版本，不代表任意历史版本支持所有后来新增的原版功能。

另已正常关闭 Pro，实际启动桌面原版 `2.5_2026-01-09_20-24-54.b2389cd`，确认主界面显示、机器未启用，没有配置读取错误。软件专项测试 95 项通过。

自动调优、坐标还原、身份迁移、旧版严格读取及既有图像/包络测试共同用于验证；用户配置和相机照片不纳入源码。
