# 钢网夹具设计 · YAA2000-GWJJ

入口：**窗口 → 钢网夹具设计**，也可从“实验功能”菜单打开。

1. 填写夹具型号和 PCB 长、宽、厚。参数区每行两项，分为“基本、公差、结构、刻字”四页。核对夹口距离、夹入深度和钢网上边空白距离，尺寸联动会自动计算相关值。
2. 首次使用某种打印机或材料，先生成九组转轴测试件。选择最顺畅、无明显晃动的一组，将 C 值填写为“转轴孔直径补偿”。
3. 检查结构示意及刻字位置，点击“生成三件打印模型”。完成后查看校验报告，分别打印底板、下夹片、上夹片；保持“打印姿态”页及导出文件的朝向。下夹片螺母槽朝上，上夹片沉孔朝上。
4. 使用 M2.5 螺母和所选长度的螺钉夹紧无框钢网。夹片翻到接近 90° 时，将扁轴向下放入开口轴座，再翻下刷印。取下前先翻至 88～90°，再向上提起。

工具栏第一项“保存为启动参数”会记住当前全部设置，下次打开自动载入。“导入参数”和“导出参数”用于交换 JSON 文件。不同 PCB 的参数可另存为命名配置，支持搜索、替换前确认与备份、删除和恢复。默认夹具名为 YAA2000-GWJJ，已保存的自定义名称和尺寸继续保留。

刻字为凹刻，字高按实际轮廓高度计算。勾选“点击定位刻字”后，可在二维示意或合拢的三维空白顶面点击放置；翻转、抬升和展开先归零。生成时检查文字是否进入孔槽、PCB 工作区，以及文字下方是否保留至少 0.4 mm 实心底厚。

三维支持左键旋转、右键平移、滚轮缩放、俯视、展开和快拆演示。旋转保持相机中心与缩放；点击“适合窗口”重新适配。编辑参数后，结构示意立即更新，实际三维仍显示最近生成结果。

生成文件支持单件 STEP、STL、3MF，装配 STEP 和完整 ZIP。可直接打开文件或交给 Bambu Studio。纸质标签独立于模型刻字，默认 50×30 mm，可调整纸张、保存 PNG 或选择系统打印机打印。

生成在后台执行，关闭设计窗口后继续；退出软件会停止任务，下次打开可从生成历史重新生成。参数、历史、报告和结果保存在用户配置目录的 stencil-fixtures/ 中。

钢网应为无框、平直空白上边缘的柔性钢网，刷印时须贴合 PCB。首次打印检查平整度、公差、夹紧力和释放手感。校验报告提供软件几何及干涉检查结果，实际打印后仍需试配。
