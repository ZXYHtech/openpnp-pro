# 钢网夹具设计

入口：**窗口 → 钢网夹具设计**，也可从启用后的“实验功能”菜单打开。

1. 填写 PCB 长、宽、厚，核对夹口距离、夹入深度和钢网上边空白距离。默认沿用应用中心钢网夹具 1.14.0 的 ZYF116-50 参数。
2. 在结构示意图确认取板孔和夹口方向。首次使用某种打印机或材料，先生成九组转轴测试件，试配后将选定的 C 值填写为“转轴孔直径补偿”。
3. 点击“生成三件打印模型”。完成后分别打印底板、下夹片、上夹片；保持导出的打印姿态，下夹片螺母槽向上，上夹片沉孔向上。
4. 使用 M2.5 螺母和所选长度的螺钉夹紧无框钢网。扁轴翻到接近 90° 后可装入轴座；刷印时翻下。取下前先翻至 88～90° 再向上提起。

“公差”“结构”“刻字”页提供全部现行高级参数。刻字是凹刻，字高为实际轮廓高度；不自动缩字、不扩大模型。在二维示意或合拢的三维顶面勾选“点击定位刻字”可设定位置。生成时检查文字是否进入孔槽、工作区，及文字下方是否保留至少 0.4 mm 实心底厚。

原应用导出的 schema 1 参数 JSON 和任务 parameters.json 均可导入。保存启动参数和命名配置互相独立；同名配置须在查看新旧尺寸后再次确认替换，原内容备份。配置支持搜索、软删除和恢复。

生成在后台执行，关闭设计窗口后继续。退出 Pro 会停止任务；下次启动显示中断，可重新生成。已完成文件、状态、输入、报告和日志保存在用户配置目录的 `stencil-fixtures/` 中，按型号分目录。原应用及其数据库不会改变。

三维是 Java 原生网格预览，支持旋转、平移、缩放、爆炸展开、翻转与抬升演示、打印姿态。三维显示最近选中的生成结果，编辑中的参数先看二维示意。打印文件支持单件 STEP、STL、3MF、装配 STEP 和完整 ZIP，可直接打开或交给 Bambu Studio。纸质标签独立于模型刻字，默认 50×30 mm，可改纸张并保存 PNG 或通过系统打印对话框打印。

实现使用 Java 业务/界面及随安装包提供的原生 OpenCascade 实体内核。**不安装、不嵌入、不调用 Python，不启动本地网页服务。** 当前原生实体内核随 Windows x64 安装包提供。原应用的 Python 接口和独立网页服务器被本地 Java API 和 Swing 窗口替代。

STEP 为精确实体；STL/3MF 为打印网格，线性误差目标 0.005 mm、角度目标 0.05 rad。Java 字体轮廓按实际字高生成，曲线折线化最大偏差 0.008 mm；字体版本不同可能产生细小字形差异。`cad-input.json` 冻结全部 CAD 操作、检查和导出，是可重复执行的协议 1 建模程序，替代原来的 Python 冻结脚本。报告注明几何版本 17、内核版本及软件验证结果。

所有验证均为软件验证。未执行机器运动、真实打印或刷印；首件仍应核对打印公差、夹紧力和释放手感。

开发：`native/stencil/build.ps1 -OcctSdk <官方 8.0.1 SDK 目录>` 编译内核并收集其依赖；无需此 SDK 即可使用已打包的运行时。Java 正常 Maven/Pro 安装器流程会打包内核。原生代码、许可证、下载版本和 SHA256 均随源码登记。
