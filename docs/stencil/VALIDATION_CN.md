# 软件验证记录

版本：OpenPnP Pro 2.6P3-beta59，2026-10-18。来源：应用中心 stencil-studio 1.14.0 / 几何版本 17；原生内核 OCCT 8.0.1。

- 干净源码快照全量回归：675 项，0 失败，0 错误，2 项原有外部数据测试跳过；包含独立的 4 项无界面启动保护测试。
- 对任务完成状态落盘增加同步保护后，最终钢网模块 20 项复测全部通过。测试使用内存偏好、临时配置及模拟机器，不读取用户机器配置。
- 直接运行原 Python 源码作为只读参考，保存三组参数和实体度量。Java/原生重构生成的底板、上下夹片均与参考体积及包围盒一致：体积容差 max(0.001 mm³, 参考体积×1e-7)，包围盒容差 1e-5 mm。覆盖工厂尺寸（关闭刻字以排除字体实现差异）、旧默认参数、不对称扩展加底部手指孔。
- 所有生成件为有效闭合实体，单件保持打印底面 Z=0；装配为 3 个实体。STEP 写出后重新读入，复查实体数量、有效性和体积。
- 正式夹具检查闭合、每 5° 翻转到 90°、88°/1 mm 和 90°/8 mm 取出姿态的零实体干涉；检查最长 6 mm 螺钉扫掠、PCB 槽位和凹刻工作区/剩余底厚。默认工厂夹具首次独立运行的 86 项检查全部通过；最终报告还包含对减重前实体的文字检查和减重体积度量。
- 九组转轴测试为 18 个实体、45 个翻转与抬升检查，包含补偿标记、STEP 回读、STL、3MF 和完整模型包。
- 运行时测试覆盖中文凹刻、生成后立即关闭再读取历史、运行中取消、退出时中断恢复。配置测试覆盖严格输入、原格式往返、同名再次确认、稳定 ID、旧修订拒绝、替换备份、删除恢复冲突、启动参数与标签纸张独立记忆。
- 3MF 测试检查 OPC 包关系、标准默认命名空间、毫米单位和共享顶点。标签测试检查 203 dpi 尺寸及非空黑色文字；不实际发送打印任务。
- Swing 测试及实际窗口截图检查中文字段、工厂 4 颗螺钉、尺寸联动、非法公差禁止生成、二维示意及真实三维网格。三维采用逐像素深度缓冲，避免底部减重结构错误透出顶面。

Python 仅用于开发时读取原实现作对照，不在此工具的安装包运行链路中。界面、参数、任务、存储、网格与打印均为 Java；精确 BRep 运算为本地 C++/OCCT 子进程。

本记录为软件验证，不代表实际打印、材料强度或刷印精度测试。首次打印仍应检查配合、公差和释放手感。
