# XY/Z 联动延迟与复位异常排查（beta64）

## 本次日志能确定什么

上传的日志中，控制器 TORNADOSMT V2（COM3）在连接和回零期间返回 `!!`。`G28`、后续移动和 `M400` 都遭到拒绝，但旧版未设置错误匹配规则时没有识别这个返回，继续进入 Home Marker 视觉复位。

软件请求位置约为 X434.880、Y335.652、Z0；控制器仍报告 X0.104、Y453.699、Z-26.325，X 相差约 435 mm。因此视觉投影的预期中心落在图像外，最终显示了误导性的“圆形搜索区域为空”。另一份日志还明确记录了 `ERROR: Homing cycle failed - check the max_travel settings`。日志也出现过 Top 相机设备找不到；不能将两种故障混为同一个原因，更不能仅凭日志断言控制器为何进入报警状态。

beta64 会识别 `!!`、`ERROR:`、`ALARM:` 和用户配置的错误表达式，优先于确认匹配。错误锁存至显式重连；异步发送停止下发尚未发送的队列指令。错误框显示连接名、原始返回和中文处理提示；不会自动解锁、清报警或重试运动。复位失败会清除机器及规划器的已回零状态。

相机预览仍可显示错误占位图；机器视觉采图若设备未打开、重试仍无图像则直接报相机名称、ID 和采图失败状态，不再对占位图运行识别。Home Marker 错误标明视觉复位阶段；圆形搜索错误附图像大小、预期中心、直径和搜索范围。

## 半秒停顿的证据与边界

175 次上传的底部视觉调用全部成功，且均为 1 轮、1 个拍摄步骤。平均总耗时 989.5 ms：移动准备/下发 62.4 ms，采图阶段 863.2 ms，其余流水线 38.1 ms。旧采图统计包含异步运动完成等待，不能据此说相机或图像算法花了 863 ms。日志中自动稳定平均约 138 ms。

贴装附近的样本显示，关闭真空之前的 `M400` 等待约 608～726 ms；下一轮的抬嘴到位也有约 238 ms 的等待。这些是控制器到位等待，尚无证据表明存在可直接删除的固定 500 ms 延时。真空开关、采图、检测前的必要等待仍保留。

新统计保留原 CSV 前九列，末尾增加 `motion_wait_ms`、`lighting_coordination_ms`、`settle_capture_ms`，分别记录相机到位等待、灯光控制及其可能的到位等待、采图阶段剩余的稳定/采图/转换开销。不增加拍照，不降低稳定阈值。

## 联动优化与回退

- 同一模型对象、修订号和认证修订号复用内部冻结副本及静态验证结果；换模型、修改或重新认证立即失效。每次仍重取机器位置、携带物料和共轴状态。
- 凸轮双吸嘴的整段保守 Z 包络保持不变。同一段端点的轴变换只计算两次，避免每个 0.5 mm 区间重复变换。
- 到达取放点前，先按障碍确定必要的竖直退出高度，随后边走 XY 边抬升或下降，不强制等 XY 到位才改变 Z；起点已清空时不再额外垂直抬 1 mm。通过全模型扫掠验证的路径可以使用局部间隙，传统全局安全 Z 作为回退路径，不是所有联动路径必须经过的高度。
- 标准电动飞达（ReferenceAutoFeeder/ReferenceSlotAutoFeeder）拾取后的完整抬升可替换为局部安全退出，剩余 Z 留给下一段 XY 行程；飞达须有原配置 ID 关联的已认证外形，当前坐标须匹配其示教取料点。未知飞达类型、拾取后脚本保留传统流程。贴装后没有脱料检测和完成脚本要求时也可局部退出；已有脱料检测仍在完整安全 Z 进行。
- 元件低于飞达外框时，只在该飞达关联的真实示教取料点允许选中吸嘴尖端竖直进出凹槽。不能斜穿外框，不能放行机头本体、同头另一吸嘴或邻近飞达的碰撞。
- 底部视觉按非接触目标单独规划：优先一条 XYZ 指令直接达到拍摄高度；有障碍时先竖直到局部安全位置，再在 XY 行程中调整 Z。没有人为添加的拍摄前末段竖直下降。两只带料的凸轮吸嘴切换到同一底部相机也使用此路径；拍照前仍等待真正到位和图像稳定。3D 工作台增加“预览视觉直达”，开关仍共用“一键启用 XY/Z 联动”。
- 原路径耗时按同头所有工具的安全 Z 动作和真实共享轴状态逐段模拟，包含高级规划器允许的独立轴运动，避免把双吸嘴原路径误当成只有选中吸嘴的三段运动。
- 开关和配置目录标识在当前配置内缓存，减少每段移动重复访问注册表、规范化目录和计算摘要；保存失败仍回滚，换配置重新读取。
- 纯 Z、原地旋转和特殊工具直接走原路径，单列为“不适用”，不再混入已评估回退。
- 实时规划采用 40 ms 检查预算；预算到期中止评估并走原安全 Z，不会跳过碰撞检查。首次模型复制、硬件变换等不可抢占步骤仍可能超出预算。预计节省必须超过本次规划耗时加 5 ms。
- 物料高度未填时，采用吸嘴尖已配置的最大物料高度作为保守上界，并额外计入穿板深度；没有有效上界则回退。封装本体宽/长仍必须真实填写，不能拿焊盘或视觉阈值代替。无效、非有限高度必须拒绝。
- 不再因机器正忙而拒绝保存已认证模型的启用请求；在下一段完整移动评估时生效，不改变正在执行的指令。
- 认证保存、重载和编辑失效已加入回归测试。当前 Gson 原本就保存 `volatile` 修订字段；本次没有证据表明认证因该修饰符丢失。

启用了附加 CoreXY 补偿或非零回差附加路径、模型未认证、物料外形未知、凸轮/其他吸嘴包络与障碍冲突、预计不更快等情况，仍会回退。保留这些条件不代表已自动关闭开关。原日志没有运行回退原因，所以无法追溯断定现场持续回退究竟由哪一项触发。

## 如何使用诊断

1. 实验功能 → 3D 工作台，核对模型和包络，点击“检查并认证”，再启用 XY/Z 联动。
2. “联动运行诊断”显示已联动、已评估回退、不适用次数，平均/最大规划耗时，以及按次数排列的回退原因；“复制 CSV”保留最近 1000 段。常见原因会同时写入日志。
3. “底部视觉耗时”查看三类采图阶段耗时并复制 CSV。
4. 修改物理几何后必须重新核对认证。仅切换开关、运行正常拾取/贴装不要求重复认证。不要为增加联动次数填写虚假尺寸或关闭必要补偿。

软件模拟基准：相同双凸轮吸嘴、30 个避让物体、60 次预演、预热后，beta63 平均 5.904 ms、P95 8.829 ms；beta64 平均 2.392 ms、P95 3.107 ms，均无任何运动指令。它只说明该软件样本规划开销降低，不能换算为实机贴片节拍提升，也不足以独立解释现场半秒停顿。视觉直达和局部退出另外减少了原先的分段运动；最终节拍收益须通过现场同作业 A/B 测试确认。
