# 表格批量填充与数字计算

适用于 OpenPnP Pro 2.6P3-beta63 及以后版本。

## 一次输入，填充所选行的同一列

1. 在元件库或封装库中用 Shift 选择连续多行，或用 Ctrl 选择不连续的行。
2. 双击所选行中要修改的单元格，输入内容；也可用方向键确定列后按 F2 编辑。
3. 按 Enter，将内容填入所选行的同一列。下拉选项选择后同样批量填写。
4. 按 Esc 取消尚未提交的编辑。提交后可继续编辑，所选行和滚动位置保留。

任务、板件贴片列表和飞达列表继续使用原有的批量编辑能力。只修改可编辑项；
编号、统计数量、来源等只读项保持只读。列移动、排序、筛选不会改变实际目标行，
未选中和被筛选隐藏的行不会填写。单击已选行可以确定要编辑的列；单击未选行重新选行，
Ctrl 单击可取消其中一行。

## 数字、长度、角度和百分比

所有使用通用编辑器的数值表格单元格都可计算；是否批量填写由该列表本身是否支持多选编辑决定。

| 输入 | 结果 |
| --- | --- |
| `1 2 . 5` | 填入 `12.5` |
| `1.2 + 0.3` 或 `=1.2 + 0.3` | 填入 `1.5` |
| `10 - 0.2` | 填入 `9.8` |
| `+= 0.1` | 每行分别在原值上加 `0.1` |
| `-= 0.1` | 每行分别在原值上减 `0.1` |
| `-0.1` | 直接填入负数 `-0.1` |
| `(1 + 2) / 2` | 填入 `1.5` |
| `1 e - 3 + 0.002` | 填入 `0.003` |
| `+= 2.54 mm` | 长度列每行分别增加 2.54 毫米，自动换算单位 |
| `100 - 20 %` | 元件速度列填入 `80%` |
| `-= 5 %` | 元件速度列每行减少 5 个百分点 |

长度的单位写在整个算式末尾，如 `(1 + 2) mm`；无单位输入沿用该单元格的单位规则。
增减操作以每行显示的单位计算；明确指定单位时先换算。支持现有长度单位 `m`、`cm`、
`mm`、`mil`、`um` / `μm`、`"`（英寸）和 `'`（英尺）。不同单位的多项混写
（如 `1mm + 2mm`）暂不支持，可写作 `(1 + 2) mm`。

算式只计算数字，不执行脚本。计算使用每行原始数值，避免把屏幕显示的舍入误差累加回数据。
普通空格、全角空格、不换行空格、制表符和换行会从数值输入中自动忽略。

## 文本与错误输入

名称、描述、别名和料带规格等文本列保留原文和空格，`01` 等前导零也保留。
要在文本单元格中计算数字，请显式输入 `=1 + 2`，结果保存为文本 `3`。
文本列的 `+=` / `-=` 要求每个目标原值均为有效数字；混入普通文字时会拒绝整次数值提交。

非法算式、除零、数值超限、整数列计算出小数、无原值可增减等情况会阻止整次数值提交，
编辑框显示红边和中文提示。修正后按 Enter 重新提交，或按 Esc 取消。
已经提交的编辑沿用软件正常的配置/作业保存流程；此功能不增加批量撤销按钮。
