# 2026-10-19 底部视觉实机验证

基于 beta65 `446bd67432e920faf2a66c66996c4aaaa2365643`。本次结果只覆盖记录中的器件、相机设置和机器配置。

## 已验证的快速静态识别

机器使用 Motion 稳定检测，固定时间字段中的 200 ms 未在该模式下执行。没有通过删除一个固定 250 ms 等待来取得以下结果。

优化保留原图像阈值、器件尺寸检查、最大偏移检查和贴装前结果屏障。曝光完成后，独立流水线在图像线程处理；机器线程可以执行必要的安全抬升。处理失败或超时会停止贴装。多步骤合成、自定义脚本、未支持的流水线和实验飞拍继续走原有流程。

对符合条件的流水线，仅处理原配置搜索圆及滤波余量，随后恢复到完整图像坐标；不缩小搜索圆。不符合裁剪条件时处理完整画幅。中间图像仅保留后续 ImageRecall 实际引用的阶段，普通流水线默认保留方式不变。

| 实机识别阶段 | 样本数 | 平均耗时 | 范围 |
| --- | ---: | ---: | ---: |
| 优化前 | 2 | 239.0 ms | 174–304 ms |
| 优化后 | 6 | 76.8 ms | 58–112 ms |

这里的耗时从稳定检测开始计到识别结果就绪，不包含此前的运动、取料和贴装。平均减少 **67.9%**，不能据此声称整机贴装速度提高相同比例。样本为两种 0603 器件，每种优化后 3 颗，均完成贴装；上相机回看没有进行经标定的绝对误差测量，不能作为 0201 或零误差证明。

对同一批真实图像交替执行完整画幅和优化处理，共 50 对回放，预热后中位处理时间：

| 器件 | 完整处理 | 优化处理 |
| --- | ---: | ---: |
| C0603-2.2nF | 52.794 ms | 1.884 ms |
| C0603-120nH | 45.782 ms | 1.724 ms |

回放中心最大差异为 0.000069 像素，角度及宽高一致。这是同一图像上两条处理路径的数值一致性，不是实际机器的定位精度。

## 真实包络与双吸嘴衔接

共享凸轮 Z 的扫掠按控制器原始 Z 轨迹映射两只吸嘴，沿段取保守的连续高度范围，避免把整个 Z 极值重复套到每一个 XY 采样位置。

新增可选字段 `zIsNozzleTip`，表达机器 Z 已指向标定后的吸嘴尖端，避免再次扣除完整吸嘴长度。旧模型默认 false，不自动迁移或重新认证。固定外壳仍以实际收回基准计算，不能由吸嘴尖端位置推断。

双吸嘴连续识别只有在两个吸嘴均使用上述坐标约定、模型认证有效、完整凸轮扫掠通过且下一段为直接路径时，才允许省去中间收回；否则维持原抬升流程。此功能通过软件测试，尚未在当前机器启用。

当前机器固定外壳与底部相机的净空尚未确定。操作员确认不能保证至少 10 mm，因此没有修改已认证模型，也没有执行被包络拒绝的低位横穿路径。

## 固定方向飞拍的实测边界

保持普通贴片路径和静态识别结果，额外被动记录一轮双头运动，共 69 帧。4 帧在接收时对应规划中的 XY 运动，但其中包含前一只吸嘴或收回高度的图像。后者宽度约 44–45 像素，正式拍摄约 65 像素；这些图像不能直接拟合成同一高度、同一器件的固定偏移。

这轮两颗器件按静态识别完成贴装，随后上相机回看、保存历史任务并清除诊断钩子，没有应用飞拍补偿。

固定方向可以减少系统性差异，但校准还必须约束吸嘴、速度、拍摄高度、曝光和帧归属。现有实验实现按整段时间线性插值位置，不能准确描述加减速；主机接收时间也不是曝光时刻。下一步需要先测得外壳及相机的真实尺寸，认证同高度定向拍摄通道，再分别为两个吸嘴采集训练和独立验证数据，最后用实际贴装后的上视觉误差验收。验证不足时继续使用快速静态识别。

## 通信与检查

当前控制器是通过 usbser 连接的 Smoothieware 原生 USB CDC 设备。此接口不按配置中的 UART 波特率限速，提高 115200 的设置不能直接缩短传输时间；未修改波特率或删除运动同步命令。

软件专项验证共 **89 项通过，0 失败、0 错误**，覆盖图像区域与坐标恢复、流水线图像生命周期、识别失败恢复、飞拍预旋转、严格采图、真实凸轮扫掠、吸嘴更换联动禁用和旧模型兼容。没有把用户机器配置、任务文件或原始照片纳入源码。
