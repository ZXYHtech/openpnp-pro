# 3D 工作台：XY/Z 联动

## 一键启用

1. 打开“窗口 → 实验模式 → 实验功能 → 3D 安全工作台”。
2. 首次使用先导入当前机器坐标，核对工作台边界、飞达、电路板、相机外壳及所有吸嘴的包络，完成“检查并认证”。示例模型不能直接作为实机依据。
3. 点击顶部“一键启用 XY/Z 联动”。开关按机器配置目录分别记忆，重启后保留；它不会自动启用另一份机器配置。
4. 再次点击“关闭 XY/Z 联动”即可恢复原安全 Z 路径。模型编辑、撤销、导入或认证失效后，联动自动暂停，状态会说明原因；重新认证后恢复已保存的请求。

“底部视觉耗时”查看本次启动最近 1000 次真实静拍调用，并支持复制 CSV；首次打开没有记录时正常显示空状态，作业识别后刷新即可。统计不增加采图或运动。底部视觉进一步提效的诊断见 [底部视觉优化](BOTTOM_VISION_OPTIMIZATION_CN.md)。

运动提速验证中心共用同一个开关，不需要选择加速等级。启用操作不会移动机器，也不会自动认证模型。

## 实际改变的运动

正式任务中的标准吸嘴取料、贴装及通过 `moveToLocationAtSafeZ` 进行的底部视觉定位，会逐段评估是否可以在 XY 行进过程中抬升或提前下降。先尝试经完整模型验证的低空直达，避免不必要的全高度抬升；直达有障碍时，再尝试联动抬升、巡航和提前下降。首末保留必要的垂直退出与取放，起点已在巡航高度时省去多余抬升航点。

沿用当前速度、轴限速、加速度和旋转终点。先退出到模型验证的局部安全高度，然后在 XY 行程中继续调整 Z；起点已清空时立即开始 XY，不额外垂直抬升。标准电动飞达取料后、无需完整安全 Z 检测/脚本的贴装后，抬嘴可止于局部安全位置，剩余 Z 由下一段联动完成。未知飞达或模型、已有脱料检测和完成脚本仍走完整安全 Z。飞达后处理、真空检测、释放顺序保留。没有新增拍照或固定等待。

底部视觉是非接触目标，可以在 XY 行程中到达准确拍摄 Z，无需保留取放用的末段竖直下降。两只带料凸轮吸嘴切换视觉也逐段验证后同步 XY/Z；若直线受阻，先竖直到局部安全位置再边移动 XY 边调整 Z。拍照前仍等待实际到位和图像稳定。“预览视觉直达”按运动/预演页填写的拍摄 XYZ 展示同一规划逻辑，不移动机器。

更换吸嘴不参加 XY/Z 联动。beta65 明确排除自动装嘴、卸嘴及手动换嘴的整个调用流程，包括进入换嘴起点、事件脚本和随后的校准，均保留原有安全 Z 分段与示教顺序，不提前下降或缩短退出。换嘴完成或异常退出后自动恢复普通贴片的联动资格，保存的开关不变。上述“双吸嘴切换视觉”只指两只已安装吸嘴轮流到相机拍照，不是到吸嘴库更换吸嘴。

只有碰撞与软限位预检全部通过、且软件估算确实更快的路径才启用。无法优化的段继续走原有安全 Z 流程。同一任务可以同时包含联动段和回退段，顶部显示数量及最近原因。

## 预览与效率评估

在“运动/预演”页填写目标 XYZ 和速度，点击顶部“预览联动路径与耗时”。3D 视图显示正式规划器生成的同一条路径，并对比原分段移动和联动移动的估算耗时。预览不执行运动，也不改变开关。

估算使用实际轴映射、速度、加速度、驱动限制及 OpenPnP 的运动曲线；它不是实测整板贴片时间，不包含真空、相机及控制器通信等全部开销。无法找到更快且安全的联动路线时，直接说明回退原因。

## 放行条件和回退

- 吸嘴使用标准 ReferenceNozzle，具有完整 XYZ 映射、安全 Z、有效且经操作员认证的模型，所有吸嘴都有包络；正式执行时机器须启用并回零。
- XYZ 和旋转须由同一控制器协调执行。Gcode 驱动还检查单行 G0/G1 命令是否包含全部相关轴变量。支持独立 Z、共享直线 Z，以及 OpenPnP 的单臂/跷跷板凸轮双吸嘴 Z。通过实际轴变换计算另一只吸嘴高度；凸轮联动按整段完整 Z 范围保守扫掠，避免把非线性凸轮误当作匀速直线。原始电机坐标用于去重，避免“选中吸嘴坐标只变一点、另一只却移动很大”被漏掉。探针、特殊吸嘴、尚不能验证的其他轴变换和跨控制器运动保持原路径。
- 多头和同头其他吸嘴一起检查，携带物料按外形半对角线形成旋转包络，并计入物料高度。物料尺寸未知时保持原路径。
- 连续的小段扫掠盒覆盖采样点之间的空间；圆柱及自定义轮廓采用保守外接盒，可能拒绝一条本来可用的路线。飞达/电路板只允许选中吸嘴尖端在首末垂直段接触，斜穿、机头本体碰撞和相机外壳均不放行。
- 开启会增加附加运动的轴回差或 CoreXY 方向补偿时，保留补偿并回退原安全 Z，避免按一条直线验证、实际却执行额外补偿路径。
- 已验证的联动段使用协调运动标志，禁止高级规划器自动改成各轴独立运动。所有航点在首条指令发出前通过软限位检查。执行中发生驱动错误时交给原有作业恢复，不再次补发回退路线。

这是基于已录入模型的软件路径优化；未建模障碍物和几何误差仍需现场核对。本次软件验证不连接真实贴片机。
