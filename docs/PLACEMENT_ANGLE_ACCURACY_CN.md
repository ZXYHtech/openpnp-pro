# 贴片角度换算与速度

底部视觉既有流程在移动途中预转吸嘴，使用已有识别结果计算最终贴片角度。真空执行器默认在动作前等待运动完成。本次保留这些运动和同步机制，不增加照片、视觉循环、旋转段或固定延迟。

修复内容是相机坐标和机器坐标的角度换算。原实现对角度直接取负值，隐含横纵每像素长度相同；位置偏差则已经分别乘以 X、Y 标定比例。现在对同一个方向向量应用相同的比例后，再计算角度：

`physicalAngle = atan2(-sin(imageAngle) * unitsPerPixelY, cos(imageAngle) * unitsPerPixelX)`

例如 X 为 0.010 mm/像素、Y 为 0.0102 mm/像素时，图像 45° 对应的物理方向约为 -45.567°，不能直接当作 -45°。横纵比例相等时保持原结果；缺少有效比例时沿用原行为。保留完整圈数，避免 ±180° 边界突跳。

同时提供反向换算，用于预旋转管线的期望角度和多图拼接结果回传，避免对同一角度补偿两次。普通底部视觉、预旋转和飞拍沿用同一换算，不新增开关或视觉步骤。

推导依据：OpenCV 相机标定模型分别使用横、纵焦距 `fx`、`fy`，像素方向需要应用相应的反投影比例。上述方向公式是对该模型以及当前毫米/像素标定的向量变换推导。见 [OpenCV 官方相机模型](https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html)。

软件测试覆盖横纵标定不等、象限及多圈往返、与位置向量一致、组合视觉反向编码、默认等比例相机和无标定回退。本修复针对标定比例造成的角度误差；机械回差、微步误差、吸嘴打滑及识别噪声仍需实机测量区分，不据此声称已经消除所有角度偏差。
