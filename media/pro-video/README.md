# OpenPnP Pro 功能演示视频

本目录包含 OpenPnP Pro 2.6P2 的功能介绍成片、真实界面素材、生成式工业视觉素材和可重复生成脚本。

- 当前成片：`OpenPnP-Pro-2.6P2-功能介绍.mp4`
- 六宫格预览：`OpenPnP-Pro-2.6P2-功能介绍-预览.bmp`
- 上一版动态成片：`OpenPnP-Pro-2.6P2-功能介绍-动态版.mp4`
- 第一版留档：`OpenPnP-Pro-2.6P2-功能介绍-初版.mp4`
- 分镜文案：`PRO_VIDEO_SCRIPT_CN.md`
- 当前生成脚本：`make_video_actual_ui.py`
- 真实界面渲染器：`ProVideoUiCapture.java`
- 真实界面素材：`actual-ui/`
- 生成式工业视觉：`generated/`

当前成片规格为 1280×720、30 fps、81 秒、MPEG-4 视频与 AAC 音频。

画面以 OpenPnP Pro 自身渲染的工作区、生产看板、元件库、封装库、飞达、单板和备份中心为主体，加入页面切换、鼠标点击、表格操作、快捷键、悬浮窗停靠与视觉校正动画；机器贴装、底部视觉和共享数据安全镜头采用生成式工业视觉素材。全片不使用简单的整页缩放作为主要动画。
