# CoreXY 原生模块与独立插件

本模块保留 TornadoSMT CoreXY v3.1 rc3 的完整 Java 内核、脚本工具箱、配置格式与原文档，同时新增自动校准流程。Pro 的入口为“机器 → CoreXY 自动精度校准”。

Pro 安装器自带运行时，不需要另外安装 Java。Pro 使用运动规划器原生入口，跳过 Agent 注入。独立 Windows 插件包也包含运行时，并用 `-javaagent` 启动原版 OpenPnP；不要求用户安装 JDK 或允许自附加进程。软件内核仍然使用 Java。

## Pro 操作（beta55）

1. 在机器配置中启用并设置视觉 Home，连接机器并完成 Home。打开“机器 → CoreXY 自动精度校准”。
2. 首次使用在“校准设置”页对齐并记录四个临时覆盖点，Home 自动读取。填写 marker 直径、目标 P95 和测量 Z；通常无需展开高级参数。
3. 点击“自动校准并启用通过方案”，自动采集、比较模型并独立评估；通过才保存与启用。顶部常驻显示补偿状态与下一步，Home 后录入按钮自动更新。
4. 有保存方案时默认显示“补偿状态与验证”，日常使用先完成 Home。四个临时点在校准后可移除；需要“5点精度验证”或重新校准时再按原位置放回。
5. 历史、原始数据、点位保存、演练和停用位于“更多操作”。旧 5×5 / 9×9 向导已由 Home + 四点界面替代，原插件工具箱仍保留。

“离线演练”使用独立物理模型模拟带轮预载、A/B 耦合、速度/加速度、位置、温度、振动和图像噪声。它不启用真实机器参数，不能替代实机精度证明。

## 实验版与原插件自动互斥（beta49）

原插件、新版独立插件与 Pro 可以保留在磁盘上。使用实验版实机校准时，先单独评估此前方案，再自动停用旧 Agent 补偿、旧 dry-run 和旧 CoreXY 规划器；后续训练和验证只使用实验版。离线演练不改动真实补偿配置。

- 首次切换保存原始正式参数、当前临时参数及规划器 XML，位于 `backups/experimental-interlock-时间-编号/`；旧参数值保留，正式配置中的 `enabled`、`dry-run` 变为 `false`。校准报告显示备份位置。
- 新方案验证、保存成功后，旧补偿保持停用；每次启动加载实验版档案时再次执行互斥，包括后来重新安装或覆盖的旧配置。旧脚本重新加载正式/临时/即时启用参数，或再次打开旧规划器补偿时，会被拒绝；不会清除正在使用的实验版偏移。
- 校准取消、失败或方案保存失败时，恢复校准开始前的方案和原始参数。若恢复失败则阻止生产，不同时运行两套补偿。
- 在机器菜单的自动精度校准中停用补偿后，旧插件仍保持关闭；需要使用时，再通过原工具箱明确启用旧方案。切换必须先完成 Home，不能直接丢弃已有活动偏移。

互斥不删除插件、脚本或旧参数。独立插件使用包内“启动 OpenPnP 与 CoreXY”启动器，让新版内核优先加载；保留原插件文件仍可复用原工具箱。

## Home + 四个临时 marker：校准与日常复位

Home 基准需保留；另外四点只在校准或手动五点精度验证时放置。Home 行从机器配置读取，只需手工记录四个覆盖点。同一平面、清晰无遮挡并覆盖工作范围；具体位置按机器可达范围选择。

首次校准保留训练、选型与最终独立验证。后续普通 Home（包括启动后的首次 Home）只检查并修正 Home 基准，不自动访问四个临时点。需要检查全工作区时，从机器菜单手动运行“5点精度验证”。对旧模型基准方案的一次转换，可能仍需原基准 marker；完成并保存 Home 参考后才可移除相关临时点，原模型与快照保留。

五点验收以校准保存的未补偿基线和测量噪声判断实际改善，目标精度作为提示；不直接把校验数据写入模型。手动五点失败会中止该次操作并要求重新 Home；不把失败记录改成通过，也不强制每次普通复位重复完整五点测试。

机械开关寻零阶段仍必须使用原生安全流程。补偿不能凭空知道本次开关的偏移：Home marker 的视觉测量提供新坐标基准，修正只重新定义当前 XY 工作坐标，不修改轴的机械 Home 配置，也不执行固件重启。Home 点即使在行程边缘，也可从行程内的安全相机位置观察，无需相机中心越过软限位；软件会预检圆点、最大漂移及补偿余量是否能完整落入视野。视野不足、marker 丢失/歧义、过大漂移、噪声过大、未收敛、独立校验退化或无法保存校验记录时，Home 不作为生产可用的复位完成，保留原方案和已采集数据供处理后重试。

完整校验按保存方案的未补偿基线、实测 P95、RMS、最大偏差和测量噪声判断实际改善；稳定性通过与“达到目标精度”分别说明。校验数据不会直接覆盖已验证模型，避免把 marker 移动或测量噪声误学成机器补偿；调整 marker、相机、驱动器、轴映射等配置后应重新校准。5 点适合全局换向、复位漂移及低阶空间误差；无法证明未采样位置的局部误差全部消除。手工相机录入支持相对于固定基准的重复定位评估；绝对长度精度仍需要经过标定的坐标基准。

保存位置是当前 OpenPnP 配置目录内的 `scripts/TornadoSMT/OpenPnP-CoreXY/precision/`：

- `fixed-markers.json`：可跨启动继续使用的 5 点设置。
- `sessions/`：每次正式校准的设置、候选评估、最终结果与原始 CSV。
- `profile.json` 与 `profile.sha256`：当前方案和完整性校验；`solutions/{方案编号}/` 保存不可覆盖的各次方案快照，与校准报告关联。
- `verifications/`：每次启动、手动或 Home 校验的会话编号、方案编号、机器指纹、Home 偏移及修正值、完整原始 JSON、`home.csv` 和 `markers.csv`。
- `history.html`：按历史数据重新生成的中文浏览页面；`simulation/` 单独保存演练资料，不启用到生产。

独立插件同样提供这一模式和 Home 前的 Agent 钩子；仍通过原有自动校准脚本打开新向导，不需要新增启动步骤。
## 独立安装

将 ZIP **完整解压到固定目录**，双击“安装独立插件.bat”，选择原版 OpenPnP 安装目录和配置目录。安装器保留已有 `machine.xml`、正式 CoreXY 参数及自定义脚本，并备份原 Agent。安装后用生成的“启动 OpenPnP 与 CoreXY.bat”启动，在“脚本 → TornadoSMT → A_CoreXY_Auto_Calibration”打开新界面。原工具箱和全部原脚本仍可使用。

插件包含 Windows x64 运行时；开发者可从同一 `org.openpnp.corexy` 源码构建其他平台版本。完整 Pro 仓库打包入口为 `package-corexy-extension.ps1`。独立包的 `source/build-source.ps1` 可使用已有原版 OpenPnP 安装目录作为 API SDK，重新编译源码；它接受 `-OpenPnpDirectory` 和 `-JdkDirectory` 参数。只有开发编译需要 JDK，普通安装和使用不需要。原版兼容性由反射检查及外部 Agent 测试验证，不以版本名称代替 API 检查。

## 各优化方案及条件

| 方案 | 实现与启用条件 |
|---|---|
| 累计换向、连续预载 | 分别累计 A=X+Y、B=X−Y 的逻辑行程；补偿动作不进入换向历史；短分段与长段一致 |
| A/B 耦合 | 增加联合状态项，四种方向组合参与采集和独立评估 |
| 公共偏置 | 独立常数项；没有外部绝对基准时只相对于本次 marker 基准 |
| 空间几何 | 比较刚度相关仿射场与双线性二维网格；不重复叠加同一几何基；工作区外使用边界值 |
| 状态空间网格 | 同一位置分别测 A/B 四种状态，拟合方向与位置相乘的二维误差图；独立路径决定是否采用 |
| 动态误差 | 速度与加速度分别变化，拟合独立特征；实测比较等待时间，使用原始相机图像避免内置 settle 延迟干扰 |
| 温漂 | 使用指定 Actuator 的真实温度；数据跨度至少 2°C；运行时检查数据有效性与新鲜度；无传感器时明确跳过 |
| 吸嘴、角度、高度 | 先校准已配置的原生 runout 和相机位置，再评估多高度/角度模型；新模型替代对应原生工具偏移，避免双重补偿；需有效底部视觉及高度像素标定 |
| 标定板误差分离 | 四次平移/旋转姿态，动画引导人工放置，其余采集与求解自动进行；同时估计各姿态的小角度放置偏差（±2°），检查矩阵秩；标准长度和参考方向用于消除比例/旋转不可辨识性 |
| 振动输入整形 | 受支持的 Klipper 固件提供 `SHAPER_CALIBRATE`、加速度计和 `SET_INPUT_SHAPER` 时执行真实控制器校准；保存可恢复参数，不调用会重启的 `SAVE_CONFIG` |
| 测量与独立验证 | 基于图像噪声设改善门槛；训练、选型与最终补偿实测分离；没有改善、最差误差退化、超限、传感器失效或取消时拒绝/回滚 |

重校准会先实测已经启用的旧方案，新方案还需不劣于旧方案。Home 初始预载由另外三次 Home 观测估计，最终验证包含 Home 后首次运动。等待时间只在新运动结束后应用一次；纯 Z/角度变化保留上一次 XY 速度与加速度。速度、加速度、温度和空间查询超出已采样区间时使用边界值，不能把外推结果当作经过验证的精度。

报告提供 `training.csv`、`validation.csv`、`baseline-final.csv`、每个候选的 `candidate-final-*.csv`、选中方案的 `final.csv` 和旧方案的 `previous-profile-final.csv`。参数保存失败会恢复旧档案及启用状态；档案损坏仍可停用补偿，不会因此锁住回退入口。

缺少硬件或可观测条件的功能不会被假装启用。自动校准需要连接、Home、空吸嘴、已验证的双向软限位和可见 marker。空间绝对精度需要已标定的尺寸基准，普通打印板不能证明绝对比例。

## 研究依据

实现采用下列材料的可验证思路，而非照搬论文中的实验精度数字：

- [CoreXY 动态建模与辨识，RCAR 2018](https://group-iris.com/wp-content/uploads/2024/06/2018-Dynamic-Modeling-and-Characterization-of-the-Core-XY-Cartesian-Motion-System.pdf)：A/B 运动映射、动态项与速度影响。
- [LuGre 摩擦模型原文，1995](https://lucris.lub.lu.se/ws/files/6363840/8498924.pdf)：用内部预载状态描述摩擦/滞回；本实现是需要独立验证的低阶端点近似，不声称完整 LuGre 参数辨识。
- [XY 耦合刚度建模，2006](https://www.sciencedirect.com/science/article/abs/pii/S0890695505001793)：联合状态的依据。
- [功能点定位误差，2023](https://ope.lightpublishing.cn/en/article/doi/10.37188/OPE.20233112.1761/)：应验证实际工具点，不能只看顶相机端点。
- [二维测量自校准，2019](https://www.sciencedirect.com/science/article/abs/pii/S0141635918304197)：多姿态误差分离与可辨识性。
- [Panasonic JP2016092019A](https://patents.google.com/patent/JP2016092019A/en)：二维位置误差与标记/基板误差的分离。
- [CyberOptics US6535291B1](https://patents.google.com/patent/US6535291B1/en)、[US6744499B2](https://patents.google.com/patent/US6744499B2/en)：旋转、成像与高度校准。
- [Micron US5247844A](https://patents.google.com/patent/US5247844A/en)：实际贴放测量应与机器端点验证区分；Pro 原有试贴纠偏流程继续保留。
- [LinuxCNC 补偿源码](https://github.com/LinuxCNC/linuxcnc/blob/master/src/emc/motion/control.c)：正反向补偿、命令与报告坐标分离。
- [Klipper 几何校正源码](https://github.com/Klipper3d/klipper/blob/master/klippy/extras/skew_correction.py)、[控制器校准命令文档](https://www.klipper3d.org/G-Codes.html#shaper_calibrate)：可逆坐标关系及真实输入整形接口。

软件测试不证明所有硬件上的精度，也无法证明绝对不存在 bug。此次交付不执行实机运动测试；软件验证范围见 [VERIFICATION_CN.md](VERIFICATION_CN.md)。原插件作者文档保存在 `upstream-docs/`，特别是 `STATE_VS_ABSOLUTE_RESIDUAL.md`，用于区分相对改善和绝对偏差。
