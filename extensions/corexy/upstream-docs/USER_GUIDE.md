# CoreXY 外置重复定位补偿使用说明

## 一、工具用途与适用范围

本工具用于检测并补偿贴片机上能够稳定复现的方向状态微小剩余误差，例如 X 轴往返后留下 Y 方向偏差、Y 轴往返后留下 X 方向偏差，且误差在相同方向、距离和速度下具有一定一致性。

工具通过顶部相机观察主要标定点，分别测量 `A=X+Y` 和 `B=X-Y` 两条虚拟传动链，生成二维状态补偿。应用后可用健康检查或空载往返检查验证，最终由外置 Agent 在 OpenPnP 运动规划阶段持续应用固定向量。

固定向量不能替代机械维修。皮带松动、拖链拉力变化、皮带轮或紧定螺钉松动、横梁不能稳定复位、导轨卡滞或视觉漂移应先处理机械或视觉根因。二维位置误差图属于后续独立功能。

## 二、实现边界

本补偿不同于 OpenPnP 原生单轴 backlash。它不改写普通 G-code，也不发送 `G92`；规划器把逻辑运动转换为驱动运动时插入状态偏置，并从位置回报中扣除驱动偏置，因此 OpenPnP 逻辑坐标保持不变。

整个系统不修改 OpenPnP 源码或安装文件。正式参数、测量数据、候选和报告保存在 `.openpnp2/scripts/TornadoSMT/OpenPnP-CoreXY/`。

## 三、准备工作

1. 检查主动轮、紧定螺钉、皮带张力、惰轮、横梁正交和导轨阻力。
2. 在工作台中心附近放置标定板或 Mark 点，在“检测与诊断”中设置 Primary 的 X/Y/Z 和特征直径，X、Y 不得为 0。
3. 开始新标定前，机器必须 Disable 且未 Home。
4. 清空测试范围、吸嘴坞及 N1/N2 中的吸嘴，确认 Safe Z 和水平路径安全。
5. 新标定会把原生 X/Y backlash 设置为 `None` 并保存，工具不自动恢复；请先手工备份 `.openpnp2/machine.xml`。

新机器用户如果已经完成上述 OpenPnP、机器和机械准备，直接使用新机器安装包。安装后第一次启动会自动识别顶部相机 X/Y 控制轴并建立全零初始化配置，无需手工填写轴 ID，也不得导入其他机器的私有数据包。详见 [NEW_MACHINE_ONBOARDING.md](NEW_MACHINE_ONBOARDING.md)。

## 四、开始和采集

1. 在“当前状态”点击“开始新标定”并确认。
2. 工具建立独立同期 Session，加载未补偿基线模式并自动 Disable。
3. Enable 并正常 Home。
4. 按当前状态提示进入“检测与诊断”，采集未补偿 Primary 网格。
5. 采集完成后生成固定向量候选，界面自动转到“候选与应用”。

固定参数为：距离 15、28、34、60、180、270 mm；速度 40%、70%、90%；每个条件重复 3 次。旧 Session 只作历史记录，不会混入新候选。

## 五、候选、应用和停用

推荐值会自动填入，补偿比例默认 100%。补偿停用时可选择 25% / 50% / 75% / 100%，也可人工修改 A/B 阈值、二维修正量及启用项。

点击“应用补偿”后，Tuner 等待运动停止、自动 Disable、把当前值写入正式配置并清空 A/B 状态，不执行抵消运动。参数随即锁定。确认没有生产任务后再操作，并在应用后重新 Enable 和 Home。

“停用补偿”可在没有生产任务时使用，同样会等待静止、自动 Disable 并清空状态。向量仍保留，界面重新载入同期推荐值并解锁参数。停用不恢复旧 CoreXY 配置或原生 backlash；无补偿运动前也必须重新 Enable 和 Home。

## 六、验证和健康检查

应用并重新 Home 后，可进行：

- “空载往返检查”：受监督的运动和体感检查，默认 L1 50 mm、5 个循环，测试前自动移动到 Safe Z。
- “健康检查”：使用正式网格的视觉定量检查，可重复执行，并刷新残差分布右侧图和最新报告。

健康检查运行期间按钮不可用，结束后机器自动 Disable。再次检查前必须重新 Enable 和 Home。

顶部相机 X/Y `units per pixel` 的较大值四舍五入到 `0.001 mm/px` 后作为门限基准：PASS 参考线为 3 像素，WARNING 参考线为 6 像素。若某个同速度/同距离单元超过 PASS 线，系统在同一次检查中自动追加 7 次复测再给出综合结论。

`P95` 表示 95% 的测量结果不超过该值，比单次最大值更适合观察总体稳定性。自动标准可能比实际生产要求严格；FAIL 不会自动停用补偿，用户应结合 P95、最大值、复测和生产要求决定后续动作。

## 七、残差分布

上方“绝对落点分布”以 Primary 为原点。散点方向表示落点偏向哪一侧，距离越远表示绝对定位偏差越大，点云越集中表示重复性越好。灰色 0.05 mm 圈只作视觉参考，不是健康 PASS 门限。

颜色固定使用暖色表示 A、冷色表示 B。上方散点使用红色 A+、橙色 A-、蓝色 B+、青绿色 B-；下方曲线在 A/B 色系内分别用三种颜色表示 40%、70%、90% 速度。曲线表示一对正负返回状态的分离，因此不与某一种单独的正向或负向散点一一对应。

下方“方向状态残差”表示同一速度和距离下相反返回方向之间的二维差，是固定 A/B 向量主要优化的对象：

```text
残差 = sqrt((正向返回X - 负向返回X)^2 + (正向返回Y - 负向返回Y)^2)
```

横轴是运动距离（mm），纵轴是方向状态残差（mm），越接近 0 越好。补偿前后趋势图使用相同纵轴尺度，鼠标移入图形可读取当前距离和各曲线残差。

按以下顺序阅读：

1. 点云中心离原点越近，绝对定位越准。
2. 同色点越集中，该返回状态的重复性越好。
3. A+ 与 A- 越接近，A 状态误差越小；B+ 与 B- 同理。
4. 四种颜色整体向同一方向平移但仍集中，更接近 Primary 基准漂移或位置相关误差，不应继续当作固定 A/B 状态误差修正。

健康 PASS 与绝对落点是否进入 0.05 mm 圈是两项独立结论。残差页和健康报告会分别给出主要误差链、补偿降幅、绝对偏向及 PASS/WARNING/FAIL 对应建议。

残差页底部点击“解读信息”会打开独立的非模态窗口，其中集中显示残差公式、图形阅读方法和针对当前测量的自动结论。解读窗口打开时仍可查看、缩放或切换主 Tuner 页面；关闭后可随时再次打开。

## 八、语言和报告

Tuner 默认中文，可在“当前状态”切换 English。语言偏好独立保存，切换不会重载 Agent、改变 A/B 状态或触发运动。报告保留中英并列字段，技术枚举、单位、Session ID、路径和 SHA-256 保持不变。

## 九、安全原则

- 任何自动运动前检查台面障碍、吸嘴、夹具、飞达、PCB 和线缆。
- 软限位不能识别实体障碍物，Safe Z 也不能替代水平路径检查。
- 应用或停用补偿时不得有正在执行的生产任务。
- 每次配置切换后必须重新 Enable 和 Home。
- 机械结构、相机标定或关键配置变化后重新完成整套标定。
