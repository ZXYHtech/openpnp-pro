# Tuner 双语界面约定

## 当前实现

- 初次运行默认中文。
- 用户可在 Tuner 中切换中文或 English，选择写入外置 Tuner 首选项。
- 切换后立即刷新页签、按钮、状态提示和说明；正在运行的测量窗口在下次打开时使用新语言。
- 文本报告保留完整英文，同时增加对应中文；数据键和值不因语言改变。

语言首选项保存在 `OpenPnP-CoreXY/config/ui-language.properties`，与正式补偿配置分离。切换语言不会调用 Agent 重载，不会改变 A/B 状态，也不会触发机器运动、Disable 或 Home。

## 边界

以下内容翻译：

- 页签、按钮、字段名、工具提示、状态和下一步指引。
- 确认、完成、警告和错误弹窗。
- 测量进度阶段名及健康检查报告的解释文字。

以下内容保持稳定，不翻译：

- 属性文件键名、文件名、Session ID、SHA-256 和路径。
- `PASS`、`WARNING`、`FAIL`、`A+`、`A-`、`B+`、`B-` 等协议枚举。
- mm、mm/px、RMS、P95、UPP 等单位和指标缩写。

## 实现约束

- 语言偏好建议使用 `ui.language=zh_CN|en`，默认 `zh_CN`。
- 使用单一 `text(key, ...)` 入口读取资源，禁止在业务分支中各维护一套流程逻辑。
- 中文和英文共用同一数值格式化及判定结果，翻译层不得参与测量或验收计算。
- 报告优先采用“中文 / English”字段标题，保证现场阅读和远程排障都可用。
- 缺少翻译键时回退中文并记录键名，不允许因文本资源缺失阻断机器流程。

## 覆盖顺序

1. 当前状态、检测与诊断、候选与应用、残差分布四个主页面：已接入。
2. 残差页 A/B 暖冷色图例、速度图例、坐标说明、工具提示、“解读信息”窗口和自动结论：已接入。
3. 新标定、基线采集、应用/停用、健康检查弹窗及进度窗口：已接入。
4. 使用说明和健康检查文本报告：已接入；报告固定采用中英并列。
5. CoreXY 示意页：已接入主要可见文字。
6. 保留的旧诊断工具：作为开发页面，后续按实际启用范围逐项清理。
