# 关键设计决策

## D-001 外置实现边界

采用 Startup 脚本加载的 Java Agent，不修改 OpenPnP 源码、官方安装文件、普通 G-code 或使用 `G92`。原因是便于升级、回滚和明确责任边界。

## D-002 固定 A/B 二维状态向量

当前模型以 `A=X+Y`、`B=X-Y` 的方向状态为输入，每个状态使用二维 X/Y 修正。它修正可重复状态差，不把绝对落点偏心或二维位置误差场混入同一模型。

## D-003 取消临时/正式双流程

用户界面只保留“应用补偿”和“停用补偿”。应用直接持久化页面值；停用保留参数并恢复编辑。减少旧数据、临时状态和正式状态之间的混淆。

## D-004 允许非零 A/B 状态切换

应用与停用可从 Enabled、Homed 或 A/B 非零状态发起，但前提是没有生产任务。Tuner 等待运动静止、自动 Disable、Agent 清空状态且不执行抵消运动。每次切换后强制要求用户重新 Enable 和 Home。

## D-005 生效时锁定参数

补偿生效时，补偿比例、A/B 阈值、向量和启用项不可编辑。停用后重新读取同期推荐值并解锁，防止 UI 显示值和正式配置不一致。

## D-006 默认补偿比例 100%

候选以本次同期检测结果为首要推荐，默认 100%。发生过补偿时由用户选择 75%、50% 或 25%，也可在停用状态人工调整。

## D-007 统一健康检查

不区分临时和正式健康检查。只有补偿已应用且机器 Enabled、Homed 时可运行；可多次运行，每次刷新残差图和报告，结束后自动 Disable。

## D-008 像素门限

健康门限不用实测视觉底噪直接决定，而采用顶部相机 UPP 较大值，按 `0.001 mm/px` 取整：PASS 3 px、WARNING 6 px。实测视觉噪声仍写入报告作诊断。

## D-009 自动定向复测

完整网格发现同速度/同距离异常单元时，在同一次健康检查自动追加 7 次复测并给出综合结论，不提供独立复测工作流。

## D-010 Session 和哈希隔离

每次新标定建立独立 Session。候选绑定同期未补偿基线及其 SHA-256，健康结果绑定正式配置哈希，防止旧测量和当前参数混用。

## D-011 绝对误差与状态残差分开

0.05 mm 圈只用于观察绝对落点，不是健康 PASS 圈。A+/A-、B+/B- 的中心分离和同条件退化用于判断方向状态健康，两类结论同时展示但互不替代。

## D-012 双语与数据格式分离

默认中文，可切换 English。翻译层只影响显示，不改变属性键、文件名、Session、SHA-256、数值格式或判定逻辑；报告保留中英并列字段。

## D-013 原生 backlash 处理

开始新标定时把 OpenPnP 原生 X/Y backlash 设置为 `None` 并保存，避免双重补偿。当前不自动恢复，用户需提前手工备份 `machine.xml`。

## D-014 机械问题优先

若误差随机变化、拖链拉力不稳定、横梁不能复位或传动件松动，应先处理机械根因。固定向量不得被描述为机械维修或完整位置标定的替代品。

## D-015 新机器自动初始化

通用安装包只携带 `onboarding.state=uninitialized` 的全零模板。首次 OpenPnP 启动从顶部相机读取实际 X/Y `ReferenceControllerAxis`，要求二者不同且使用同一驱动器，然后写入当前 OpenPnP 版本并转为 `ready-for-calibration`。初始化不 Enable、不 Home、不运动；已有正式配置永不由新机器安装器覆盖。

## D-016 新机器首份基线不依赖旧生产证据

`ready-for-calibration + bootstrap-new-machine` 配置必须保持 `enabled=false`，但允许在加载未补偿 Home 基线模式后采集首份同期 Primary 基线。该采集只建立本机 Session 的未补偿参考，不要求正式补偿已启用，也不读取旧生产 review/reference。正式健康检查的持久补偿启用条件不因此放宽。

## D-017 残差图使用固定视觉语义

残差页固定使用暖色表示 A、冷色表示 B。上方散点颜色区分 A+/A-/B+/B- 返回状态；下方曲线在 A/B 色系内区分 40%/70%/90% 速度，因此曲线不与某一个正负散点一一对应。补偿前后方向状态曲线共用纵轴尺度，并同时显示图例、单位、鼠标读数和自动结论。报告结论必须把方向状态健康与绝对落点是否进入 0.05 mm 圈分开。

## D-018 图形与解读信息分离

残差页优先为四幅图保留空间，公式、阅读方法和自动结论通过“解读信息”打开独立非模态窗口。候选与应用页的滚动内容必须跟随视口宽度，在最大化和恢复窗口时重新收缩，不保留最大化后的页面尺寸。
